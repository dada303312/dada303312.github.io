# 开发日志：幸存者原型的第一轮节奏调整

![第一轮完整试玩画面](/images/blog/godot-survivors-rhythm/04-final-visual.png)

把生命、敌人分工、数据升级、波次导演和像素表现做完以后，我又连续跑了几局。

这次的问题和之前不一样。系统已经完整，角色会死，敌人有不同行为，升级能改变子弹，十分钟的波次也有阶段。但前两分钟太稳，成长不够快，敌人没有把我逼到必须做选择。玩起来像在看一套系统自己运行，而不是在玩一局随时可能结束的游戏。

我把这次试玩的感受记成三句话：升级不够快，敌人不够乱，死亡来得太晚。

## 第一次升级必须马上有用

原来的第一级需要 10 点经验。按理论击杀速度，玩家至少要打十几秒才能升级；如果经验宝石没有及时捡到，第一次选择还会继续往后拖。

第一次升级又经常只是伤害加一点。子弹从 10 变成 11.5，敌人还是两发死。系统告诉我变强了，手上却没有任何变化。

所以下一轮我准备把前几级经验门槛降到：

```text
4 → 7 → 10 → 14 → 19 → 25 → 32
```

前三次升级先只从行为型选项里抽，比如分裂射击、穿透弹、环绕刃和爆裂弹。玩家第一次升级后，我要让下一波敌人立刻被新的攻击方式处理掉。

数值升级不是删掉，只是放到后面。前期先让玩家看到“我变成了另一种武器”，而不是看面板多了百分之几。

## 敌人先靠数量和体型制造压力

上一版敌人成长主要靠波次间隔。间隔从一秒缩到零点几秒，但同屏看起来还是差不多。真正有压迫感的时候通常很晚，前面几十秒几乎没有变化。

我不想直接告诉玩家“怪物血量加了多少”。这种成长没有画面感，玩家也很难判断自己在变强还是敌人在变强。

我现在更想用小队生成：

```text
单只敌人
→ 两到四只一起出现
→ 一个带头的大体积单位
→ 两个方向同时来
→ 精英带普通单位
```

美术还没补齐之前，体型可以暂时承担一部分区分。普通单位保持原大小，强化单位放大一点，小精英再大一点。血量只做小幅增加，先把数量和体积做起来。

我还想在波次导演里加一笔隐藏压力。玩家清得太快，就增加下一波数量；玩家一直没受伤，就让敌人在两个方向同时生成。这个变化不能马上兑现，否则玩家会觉得自己被针对。

我要的效果是：前一波还能站在原地清完，下一波就必须开始移动。

## 死亡不要拖

之前的失败条件是完整的，但触发得太慢。敌人接触伤害不高，回血和无敌时间也足够宽松，玩家出了操作问题还是能撑很久。

短局游戏里，死亡要来得更早一点。第一局的死亡中位数我想先试在两到三分钟，而不是让新手稳定撑到八分钟。

但死亡不能来得莫名其妙。普通接触伤害保持可读，真正结束一局的是堆积后的小队、远程单位的交叉火力和精英的压迫。

死亡之后的流程也要缩短：

- 最后一击慢一点，让玩家看清自己是怎么死的。
- 结算只显示存活时间、击杀、主要升级和死亡原因。
- `R` 或空格可以直接重开。
- 从死亡到重新操作控制在三秒左右。

结算里我想加一句“差一点”的信息，比如差一次升级形成分裂流，或者差几次击杀进入三分钟。这样玩家会直接开始想下一局怎么打，而不是先退出游戏。

## 第一局前两分钟的目标

我现在按下面的节奏做首轮测试：

| 时间 | 我在游戏里想看到的变化 |
|---|---|
| 0:00—0:15 | 熟悉移动、自动攻击和拾取 |
| 0:15—0:30 | 第一次行为升级，攻击方式立刻变化 |
| 0:30—1:00 | 敌人数量变多，玩家开始连续清怪 |
| 1:00—1:30 | 出现小队和大体积单位，站桩变得不安全 |
| 1:30—2:30 | 远程、突进和普通敌人一起压迫，出现真正的死亡风险 |
| 2:30—4:00 | 玩家已经知道自己想做什么构筑，开始重开尝试 |
| 4:00—10:00 | 熟练玩家继续完成整套波次和 Boss |

第一局最重要的不是让玩家学会所有系统，而是让他在两三分钟内经历一次完整的“变强、清场、被追上、死亡、重开”。

## 音乐和战斗节奏一起做

我一直想把音乐和这个玩法绑起来。基础射击声本来就有节拍感，如果攻击、拾取和击杀都能落在拍子上，战斗会更容易形成节奏。

我先固定一个主拍，不让攻击速度直接改变整首音乐的速度：

```text
150 BPM
四分音符 0.4 秒
八分音符 0.2 秒
十六分音符 0.1 秒
```

当前基础攻击间隔接近 0.4 秒，正好可以做第一层底鼓。

| 游戏事件 | 我准备使用的音乐层 |
|---|---|
| 基础射击 | 底鼓 |
| 高速射击 | 踩镲和连续鼓点 |
| 敌人死亡 | 军鼓或拍手 |
| 经验拾取 | 高频小音符 |
| 玩家升级 | 叠加和弦 |
| 穿透弹 | 滤波扫频 |
| 爆裂弹 | 桶鼓和低频冲击 |
| 环绕刃 | 延迟琶音 |
| 精英出现 | 低频持续音 |
| 玩家死亡 | 各音乐层依次停止 |

演奏和反馈要分开。开火时我还是会立即播放一个短促的击打音，保证手感；真正参与编曲的音符则量化到最近的十六分音符。这样高速攻击不会把音乐打乱，也不会为了等拍子牺牲操作反馈。

第一阶段我只准备做四层：射击底鼓、拾取踩镲、击杀军鼓、升级和弦。先听这四层能不能让战斗节奏成立，再继续做旋律和电子音色。

## 已经打好的基础

这次节奏调整不需要从头搭系统，前面的工作已经覆盖了大部分底层需求。

### 四类敌人

![四类敌人职责](/images/blog/godot-survivors-rhythm/01-enemy-roles.png)

追击、突袭、重装和远程已经能放进同一波次。后面调整敌人组合就能改变压力，不需要每次新增代码分支。

### 数据驱动升级

![升级三选一](/images/blog/godot-survivors-rhythm/02-upgrade-pool.png)

升级池已经能把行为升级和数值升级分开。我可以先控制抽取范围，再慢慢调稀有度和层数。

### 波次导演

![最终围猎阶段](/images/blog/godot-survivors-rhythm/03-final-wave.png)

生成间隔、同屏上限、阶段组合和精英节点都集中在波次导演中。前期节奏可以从这里直接改。

### 像素表现和音效

角色、敌人、子弹、宝石和表现节点已经换成像素素材。射击、受击、死亡和升级也已经接入音效。下一步不需要先补视觉，才能测试节奏。

## 接下来先做这几件事

我先改经验门槛和前期敌人生命，再用试玩记录看第一次升级要多久。

接着把前三次升级固定到行为型候选里，保证每次重开都能很快形成不同的攻击方式。

然后调整生成逻辑，让敌人先以小队出现，再用体型和带头的精英增加压力。死亡流程和重开按键会一起改，避免结算打断节奏。

最后再接音乐调度。先做四层，跑一段时间以后再看是否继续叠加。

这次我不准备一次把所有数值调完。前两分钟的节奏只要能让我自己连续重开几局，下一步才值得继续做更长的一局。
