# 像素风幸存者：从能运行到抓人

![最终像素原型](/images/blog/godot-survivors-rhythm/04-final-visual.png)

上一版我把工程推进到了“能完整运行一局”的状态：角色会受伤和死亡，敌人有不同职责，升级可以改变攻击方式，十分钟波次有阶段结构，像素素材、粒子和音效也已经接入。

但把它实际跑起来后，问题很快暴露出来：系统是完整的，游戏却不够抓人。

前两分钟太稳，成长不够快，敌人没有形成真正的压迫。玩家不会因为一次选择立刻变强，也不会在短时间内经历一次明确的失败和重开。整体像一套正确运转的系统，而不是一场让人想再来一局的游戏。

## 一、抓人的不是敌人数量，是决定间隔

类幸存者的操作自动完成，玩家真正参与的是连续判断：

- 我现在往哪里走。
- 我要不要穿过怪群去吃经验。
- 我应该先补输出，还是先补保命。
- 这次升级会让我变大，还是把流派带偏。

节奏平，不一定是因为敌人少，而是因为这些重要决定之间隔得太远。

如果玩家 40 秒才升一次级，前 30 秒又不会被真正威胁，他就会进入机械移动状态。此时敌人再多，也只是一个更拥挤的背景。

所以下一版不准备简单把所有敌人数值翻倍，而是先缩短“体验变化”的间隔。

## 二、成长必须先夸张地快，再慢慢变精细

第一次升级不能只给 `伤害 +10%`。玩家感受不到，爽感也不会出现。

新的前三级目标：

1. 第一次升级发生在开局后约 10～20 秒。
2. 60 秒内至少完成三次升级。
3. 前三次优先出现会改变攻击行为的选择。
4. 每次升级后，玩家在 5 秒内必须看见结果。

前期经验门槛可以先压到：

```text
4 → 7 → 10 → 14 → 19 → 25 → 32
```

第一次升级后，优先给出分裂射击、穿透弹、环绕刃、爆裂弹这类选项。玩家从一把单发枪变成三发散射，或者从直线命中变成穿透一排怪，这种变化比任何数值提升都更容易被感受到。

纯强度型升级要退到后面，它们的作用是延长主升级的价值，而不是承担第一次成长。

## 三、敌人先变多、变大，再变硬

我也不想让玩家在前两分钟看到“怪物生命值 +30%”这类信息。数值变化太抽象，玩家更容易感受到数量、体积和速度。

所以敌人强度按以下顺序成长：

```text
单只敌人
→ 两到四只小队
→ 一个带头大体积单位
→ 两个方向同时生成
→ 精英带领的小队
```

体型可以暂时承担隐藏强度的功能：

| 敌人 | 体型 | 玩家感受 |
|---|---:|---|
| 普通单位 | ×1.00 | 清理成本低 |
| 强化单位 | ×1.12 | 需要多打一下 |
| 小精英 | ×1.25 | 应该优先处理 |
| 大精英 | ×1.45 | 这次波次的压力核心 |

后续补美术后，再用轮廓、动作、颜色和受击反馈继续区分。体型不是最终方案，但它能在没有正式素材时先让难度变得可读。

## 四、压力需要“暗账”

如果玩家一直清怪很快，系统不能立刻提高血量，否则玩家会发现自己在被针对。

更合适的方法是积累隐藏压力债：

- 清怪太快，下一波数量增加。
- 连续一段时间没有受伤，生成小队而不是单只敌人。
- 玩家生命很低时进入恢复窗口。
- 压力债在下一个波次兑现，而不是立刻兑现成伤害。

玩家不需要看到数字，只需要在战斗中产生一种感觉：

> “刚才还清得很快，怎么突然就忙不过来了。”

这种变化应该来自敌人的组合和密度，而不是后台直接修改一个明面上的倍率。

## 五、死得快，但要死得明白

你提到“死得太慢”，我非常认同。死亡不是设计失败，它应该是短局制游戏最重要的节奏节点。

第一局的死亡中位数建议控制在约 2～3 分钟，而不是让新手稳定撑到八分钟。

死亡流程也要短：

- 最后一击加入短暂慢动作。
- 屏幕震动、颜色压暗、敌人短暂停格。
- 一秒内出现结算。
- 结算只保留存活时间、击杀数、主要构筑和死亡原因。
- 支持 `R` 或空格直接重开。
- 从死亡到重新操作控制在三秒内。

结算要让玩家觉得“差一点”，而不是“我又失败了”：

```text
还差 1 个升级形成分裂流
被远程单位终结
本局最高连杀 67
```

只要玩家能在三秒内重新开始，死亡就会变成下一次尝试的入口。

## 六、首局两分钟的目标节奏

下一轮调优会优先围绕以下节奏做首轮测试：

| 时间 | 玩家体验 | 敌人与成长 |
|---|---|---|
| 0:00—0:15 | 理解移动、射击和拾取 | 少量弱怪，前几发可以一击击杀 |
| 0:15—0:30 | 第一次明显变强 | 第一次行为升级 |
| 0:30—1:00 | 进入割草状态 | 数量增加，单体仍容易处理 |
| 1:00—1:30 | 开始被迫调整站位 | 出现小队和大体积隐藏精英 |
| 1:30—2:30 | 第一次真正的死亡考验 | 夹击、远程干扰和密度上升 |
| 2:30—4:00 | 用上一局理解尝试新构筑 | 流派开始成形 |
| 4:00—10:00 | 熟练玩家挑战完整一局 | 精英节点和最终 Boss |

第一局不是教学关，而是一次完整的情绪压缩：

```text
很快变强 → 很快割草 → 很快被追上 → 很快再开一局
```

![十分钟目标节奏](/images/blog/godot-survivors-rhythm/05-run-pacing.svg)

## 七、音乐应该成为第二套战斗系统

你提出的编曲方向和这个玩法非常契合。枪声不是背景音，它可以直接成为节拍基底。

建议先固定一个音乐主拍，而不是让攻击速度随意改变音乐速度：

```text
150 BPM
四分音符 = 0.4 秒
八分音符 = 0.2 秒
十六分音符 = 0.1 秒
```

当前基础攻击间隔接近 0.4 秒，刚好可以作为第一层底鼓。

| 游戏事件 | 音乐层 | 情绪作用 |
|---|---|---|
| 基础射击 | 底鼓 | 每次开火都踩在节拍上 |
| 高速射击 | 踩镲和连续鼓点 | 听觉上直接感受攻速成长 |
| 敌人死亡 | 军鼓或拍手 | 把清怪变成节奏事件 |
| 经验拾取 | 高频小音符 | 连续拾取形成旋律 |
| 玩家升级 | 叠加和弦层 | 每次成长让音乐变厚 |
| 穿透弹 | 滤波扫频 | 打开音乐空间 |
| 爆裂弹 | 桶鼓和低频冲击 | 提供力量感 |
| 环绕刃 | 延迟琶音 | 形成旋转和持续感 |
| 精英出现 | 低频持续音 | 提高危险感 |
| 玩家死亡 | 音乐层依次停止 | 用音乐结构表达失败 |

这里有一个技术底线：即时反馈音和音乐音符要分开处理。

玩家按下攻击时，立即播放一个低延迟的击打反馈；真正的节拍音符则量化到最近的十六分音符。这样既能保证手感，又不会让高速射击把音乐打得乱七八糟。

第一阶段只需要四层：

1. 射击底鼓。
2. 拾取踩镲。
3. 击杀军鼓。
4. 升级和弦。

先用这四层验证“战斗是否真的在演奏音乐”，再录制更完整的编曲。

## 八、这一版已经打好的基础

目前原型已经具备快速节奏调优所需的底层系统。

### 四类敌人

![四类敌人职责](/images/blog/godot-survivors-rhythm/01-enemy-roles.png)

追击者维持基础压力，突袭者惩罚停留，重装体占据空间，远程单位改变站位。

### 数据驱动升级

![升级三选一](/images/blog/godot-survivors-rhythm/02-upgrade-pool.png)

升级不再是三个写死的数值按钮，而是从资源池中抽取，并能改变攻击行为。

### 十分钟波次导演

![最终围猎](/images/blog/godot-survivors-rhythm/03-final-wave.png)

波次导演已经可以控制生成频率、敌人组合、精英节点和最终 Boss。下一轮只需要替换更激进的前期参数。

### 像素表现和反馈

玩家、敌人、经验宝石和攻击物都有了像素帧；命中、死亡、拾取和升级有粒子；射击、受击、死亡和升级有音效。

这些基础让接下来的节奏调优不会停留在表格上，而可以直接在游戏里反复试玩。

## 九、下一轮实施顺序

1. 先改前三级经验门槛和前期敌人生命，让第一分钟内至少出现三次明显成长。
2. 把前三次升级改成行为型升级池，保证玩家先获得攻击形态质变。
3. 用小队生成、带头单位、体型成长为敌人增加隐藏压力。
4. 加入压力债，在玩家过强时提高下一波密度，而不是直接增加血量。
5. 压缩死亡、结算和重开流程，让失败成为下一局的入口。
6. 建立固定 BPM 的音频调度器，先接入四层基础音乐。
7. 最后再根据试玩结果调整首局死亡中位数、流派强度和音乐层数量。

## 结论

第一版证明系统能运行。

第二版要证明玩家愿意再开一局。

这中间最重要的不是更多内容，而是把成长、压力和失败压缩到一个更短的循环里。先让玩家快速变强，再让敌人快速追上；先让死亡变得清楚，再让重开变得值得。

当射击成为底鼓，拾取成为踩镲，击杀成为军鼓，升级成为和弦时，类幸存者的战斗就不仅是数字在增长，而是玩家亲手把一局游戏演奏成自己的流派。
